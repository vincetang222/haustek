Xuất & gửi

Bấm Kiểm tra & xuất hồ sơ. Nếu mọi thứ hợp lệ, máy sẽ tải về hai file: một file .json để Haustek nạp vào hệ thống và một file .csv mở được bằng Excel. Bạn gửi cả hai file này về mgmt@haustek-group.com kèm file WAV và ảnh bìa là xong.

Yêu cầu file gửi kèm
File nhạcWAV, 16-bit hoặc 24-bit, tần số 44.1 kHz trở lên, stereo. Không gửi MP3. Không để tiếng bị vỡ (clipping) ở đỉnh.
Ảnh bìa3000×3000 px, JPG hoặc PNG, RGB, dưới 10MB.
Cách gửiĐẩy lên Google Drive hoặc Dropbox rồi dán link, đừng đính kèm trực tiếp vào email.
